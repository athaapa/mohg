# mohg

A simple moog-inspired monophonic synthesizer for MacOS written in Odin.

# Features
- 1 oscillator
- ADSR
- sine, square, triangle, saw wave
- ladder filter

# Planned Features
- second oscillator
- filter + filter envelope
- LFO
- velocity/pitch bend/sustain
- polyphony
- unison
- chorus/delay
- modulation routing
- presets
